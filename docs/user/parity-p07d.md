# A site search as your default search engine

Any of a profile's site searches can be its default search engine, as on Chrome's (and Arc's) search engine page. Say
you make Amazon the default. Words you type that aren't a web address then search Amazon instead of Google.

## Choose it

1. Open **Settings → Site Search**. If you have more than one profile, pick it under **Sites of**.
2. Under **Default search engine**, open **Search with** and choose a site. It can be one of the built-in sites or one
   you added.
3. The site's row is now marked **Default**.

To go back, choose the first entry in **Search with**: the profile's own search engine (Google, DuckDuckGo, Bing, Kagi
or Ecosia, set in **Settings → Profiles**).

## What changes

- **The URL field** when the page toolbar is shown (⇧⌘D), **Paste URL in New Tab** (⌥⌘V) and **Little Airc**: words
  you type search the site. A web address you type still opens as an address.
- **The Command Bar** (⌘T, ⌘L): see "Not yet" below.
- Each profile has its own default, like its own sites.
- What you type is encoded for the site exactly as a site search encodes it: `wool & socks` becomes
  `amazon.com/s?k=wool+%26+socks`.
- Site searches still work as before: type the site's shortcut and press Tab.

## If you remove the site

If you remove the default site from the list, the profile goes back to its own search engine. Restore Default Sites
puts the removed site back in the list, but not as the default. Editing the site (its name, shortcut or address)
keeps it as the default.

## Not yet

The Command Bar's search row and private windows still use the profile's own engine. The change that makes them use
the default site is ready, and will be added once the Command Bar's current work lands.
