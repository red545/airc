# Find and Replace

**⌘F** finds on the page: every match is highlighted and the bar counts them. **⌘G** and **⇧⌘G** (or ↩ and ⇧↩ in the
field) go to the next and previous match, **Esc** closes the bar. In a note, the same bar finds in the note.

**⌥⌘F** (Edit › Find › Find and Replace, as in Arc) adds a row to replace what you find in the page's editable text:

- **Where it replaces:** if a text field, text box or editable area of the page has the keyboard when you press ⌥⌘F,
  only in it; the row says "Replace in this field". Otherwise in every editable field on the page, and in the
  frames of the page's own site: "Replace in the page's fields". Text that isn't editable stays as it is, and so do
  frames from other sites.
- **Replace** (or ↩ in the Replace field) changes the next match; **All** (or ⌥↩) changes every one. The bar says how
  many it replaced. Matching ignores upper and lower case, as finding does.
- **Undo:** the page takes the change as if you had typed it, so the site sees it (a form or editor notices the new
  text) and **⌘Z** in the page undoes it. All is one ⌘Z in a text field; in a rich text editor each replacement is
  one step. An email field takes the new text without an undo step.
- **Never** in a password field, a read-only field or a disabled one, even when it has the keyboard.
- A match that runs across differently formatted text (half of it bold, say) isn't replaced.

## Services

The **Airc › Services** menu has the Mac's services, as in any app: select text on a page (or in a note or a field)
and choose a service to look it up, open it, make a note of it and so on. A service that changes text (making it
upper case, for example) puts its result back into the page's text field or editable area where the selection was.
