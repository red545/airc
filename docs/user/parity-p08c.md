# Starting Capture

Capture (⇧⌘2), Capture Full Page and Capture in Portrait Mode do what [Capture](capture.md) describes. This page lists
where you can start each one.

| Where | Capture | Capture Full Page | Capture in Portrait Mode |
|---|---|---|---|
| The menu bar, **View** | Capture… (⇧⌘2) | Capture Full Page | Capture in Portrait Mode |
| The **Command Bar** (⌘T, type "capture", "screenshot" or "portrait") | Capture… | Capture Full Page | Capture in Portrait Mode |
| The **Site Control Center** (the slider button at the right end of the URL field) | the camera button | — (press F once Capture has started) | the second camera button |
| Inside Capture, before you select anything | — | F, or the bar's Full Page | P, or the bar's Portrait |

- **Capture in Portrait Mode** starts Capture and frames the visible page straight away, in the style you chose last.
  It uses a colour unless you picked the desktop picture. The desktop picture is only read if you choose it.
- From the Site Control Center, the card closes first, then Capture starts on the page the card was about.
- None of these has a key except Capture (⇧⌘2). You can give Capture in Portrait Mode one in **Settings → Shortcuts**.
- Private windows have the same Capture, and keep nothing.

## Not yet: the page's right-click menu

In Arc you could also start Capture from the menu you get by right-clicking a page. Airc doesn't offer that yet. The
Chromium engine only lets the app add items to that menu when text is selected, and the WebKit engine needs a small
change before it can add any. Until then, use the View menu, the Command Bar or the Site Control Center.
