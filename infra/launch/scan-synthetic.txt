# Made-up addresses and tailnet names the privacy scan approves by VALUE (scan.py --synthetic).
# <path glob><TAB><kind><TAB>net:<CIDR> | text:<exact match><TAB><reason>
# A line's private-ip or tailnet-domain hit passes only when EVERY value of that kind on the line is
# listed here for that file. Networks are at most a /24 (IPv4) or /112 (IPv6). Real values (the
# literal kinds from the private pattern file) can never be listed; scan.py refuses an entry that
# covers one. Prefer the documentation ranges, which the scan never flags: 192.0.2.0/24,
# 198.51.100.0/24, 203.0.113.0/24 (RFC 5737), 2001:db8::/32 (RFC 3849), example.com/.test names.
# See docs/launch/public-repo.md, "Made-up addresses".

# --- Pre-approved everywhere: use these for new made-up tailnet and LAN values -------------------
*	private-ip	net:100.101.102.0/24	Tailscale's own documentation example range (100.101.102.103); made-up tailnet peers.
*	private-ip	net:100.64.0.0/24	The first /24 of the CGNAT range: range-start constants (100.64.0.0) and made-up peers 100.64.0.x.
*	private-ip	net:100.127.255.255/32	The last CGNAT address, a range-end constant in tests.
*	private-ip	net:fd7a:115c:a1e0::/112	Made-up Tailscale IPv6 peers with a short host part (::1, ::42, ::1234); real peers' host parts are 32-bit.
*	private-ip	text:fd7a:115c:a1e0::	Tailscale's published IPv6 prefix as a range constant (fd7a:115c:a1e0::/48), not an address.
*	private-ip	text:fd7a:115c:a1e0:	Tailscale's published IPv6 prefix in prose ("fd7a:115c:a1e0:…").
*	private-ip	text:fd7a:	A shortened Tailscale IPv6 prefix in prose ("[fd7a:…]").
*	private-ip	net:192.168.1.0/24	The generic home-router LAN in examples and tests.
*	private-ip	net:10.0.0.0/24	The generic private LAN in examples and tests.
*	tailnet-domain	text:tailnet.ts.net	Made-up tailnet name (my-mac.tailnet.ts.net).
*	tailnet-domain	text:tailnet-a1b2.ts.net	Made-up tailnet name (my-mac.tailnet-a1b2.ts.net).
*	tailnet-domain	text:example.ts.net	Made-up tailnet name (my-mac.example.ts.net).
